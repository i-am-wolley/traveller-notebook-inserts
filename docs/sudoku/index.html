How to print it
  1. Print the imposed PDF on A4 at 100% / Actual size — never “Fit to page”.
  2. Double-sided, flipping on the short edge for regular and the long edge for passport. Hold a sheet to the light: the back of page 1 must be page 2, the same way up.
  3. Trim the dashed cut lines, fold down the dashed centre, nest the sheets in order, staple through the fold.

The guide page inside the booklet repeats all of this with the exact measurements for the book you built.
